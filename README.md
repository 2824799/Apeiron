# Apeiron

Apeiron 是 GT New Horizons（Minecraft 1.7.10）的 AE2／GregTech 扩展模组，提供大数存储与合成、无限供应、ME 输入输出和无线能源并行。

## 主要功能

- **大数计数**：扩展 AE2 物品、流体、合成请求、CPU 统计，以及适配机器的并行、能耗和产物数量，支持超出 64 位整数的数值。
- **无限供应**：创造 ME 物品／流体存储元件提供无限数量，终端显示 `∞`；编程器电路也可无限供应。
- **样板管理**：支持大数倍增、样板优化、隔离缓冲、编程电路、配方锁定和样板终端管理。
- **太空电梯**：子模块可使用主模块的无限能源仓和无线账户；普通仓保留模块原有并行上限，终极仓支持装配、采矿、抽水的大数并行和精确输出。
- **机器显示**：机器界面显示产物及数量；Waila／OmniOcular 保留机器状态、温度、存量等信息，鸿蒙之眼显示实际配方的流体需求；轻量提示包减少看向大量样板或库存时的卡顿。

## 方块

| 方块 | 用途 |
| --- | --- |
| **无限存储输入总线** | 360 个物品标记槽，直接从 ME 网络供料；支持自动标记、最小数量、模组、物品 ID、meta 和矿物词典过滤。 |
| **无限存储输入仓** | 360 个流体标记槽，直接从 ME 网络供料；支持自动标记、最小数量和流体注册名过滤。 |
| **无限存储输入总成** | 360 个共用标记槽，可混合标记物品和流体，同时为多方块机器供料。 |
| **无限 ME 输出总线** | 将机器产物送入 ME 网络，支持大数物品缓存和存储元件分区过滤。 |
| **无限 ME 输出仓** | 将机器产物送入 ME 网络，支持大数流体缓存和流体存储元件分区过滤。 |
| **无限 ME 输出总成** | 同时输出物品和流体，两者拥有独立缓存、设置和存储元件槽位。 |
| **无限样板输入总成** | 360 个样板槽、24 个隔离缓冲，支持物品与流体配方、倍增、催化剂、编程电路、配方锁定和样板优化。 |
| **无限样板输入总成镜像** | 用闪存绑定源总成，共享其样板和缓冲，不复制库存，不额外占用 AE 通道。 |
| **无限编程器电路提供器** | 81 个样本槽（9×9），将样本转换为无限供应的编程器电路；可展开预构电路提供器的整套模板。联网固定耗电 1024 EU/t，需要 Programmable Hatches。 |
| **无限能源仓** | 从 GT 无线电网扣电；默认并行上限 `2,147,483,647`，支持大数并行与可调运行电压；沿用机器自身的超频规则，调高电压可能导致有损超频；手动设并行为 `0` 才解除上限。 |
| **终极无限能源仓** | 彩虹动态贴图；按配方基础总耗电运行，完成时间默认 `128 Tick`（6.4 秒），最低 `1 Tick`，改变时间不改变总耗电。 |
| **鸿蒙之眼增强模块** | 替换一个输入仓位置；可设置运行时间（最低 1 Tick）和成功率（0～1），解除星阵数量上限；无限存储输入设备按配方缺口一次精确拉取流体，各种流体分别封顶，保留原生 EU 结算。 |
| **无限并行处理单元** | AE2 合成 CPU 部件，提供无限并行能力。 |
| **无限合成存储器** | AE2 合成 CPU 部件，提供无限合成存储容量。 |

## 安装与使用

1. 将 JAR 放入客户端和服务端的 `mods/`。需要 GTNH 版 GregTech 和 Applied Energistics 2。
2. 将输入／输出设备安装到多方块机器并接入 ME 网络。存储输入的标记不消耗物品；右侧可设置过滤和刷新间隔，最小数量支持 `1E18`、`1e18` 等科学计数法。
3. 将样板放入无限样板输入总成，可在样板终端中管理。共享时，用闪存左击源总成，再右击镜像。
4. 安装能源仓后，在电源面板设置并行（支持 `1E20`、`1e20`）；默认保留有限上限，手动设为 `0` 才解除。普通仓可设置运行电压，终极仓可设置完成 Tick 数。启动数量受材料、整批电量预算及输出容量限制；运行中余额下降时暂停并保留配方。
5. 用无限并行处理单元和无限合成存储器组建合成 CPU，仍须满足 AE2 的结构规则。

## 兼容与配置

同一 JAR 支持 GTNH **2.9.0-beta-1、beta-2、beta-3、RC-1** 对应的核心依赖，启动时自动选择兼容实现。各版客户端与服务端核心自检已通过；历史第三方模组暂未划定支持范围。

支持 TST、GT Not Leisure、TecTech、AE2 Infinity Cell、Programmable Hatches 等可选集成；使用对应功能时需安装相应模组。

配置文件为 `config/apeiron/apeiron.cfg`，可按模组开关适配。GregTech 机器 ID 默认从 `31300` 开始，需避免与其他模组冲突。

悬浮提示只展示库存和配方预览，完整内容在方块 UI 中查看。依赖完整存档数据的自定义 OmniOcular 脚本，可关闭 `mixins.waila.enableLightweightSnapshots` 并重启。
