# Apeiron

Apeiron 是 **GT New Horizons（Minecraft 1.7.10）** 的扩展模组，适合需要大量存储、批量合成和高并行生产的玩家。

它提供可容纳超大数量的 ME 输入输出设备、带独立配方缓冲的样板总成，以及可调并行的无线能源仓。你可以继续使用已有的 ME 网络，在需要的机器上更换对应仓室。

## 安装

将下载的 Apeiron JAR 放入 `mods/` 文件夹。多人游戏需要客户端和服务端都安装，并保持版本、配置一致；更新时移除旧版 JAR。

- **核心环境**：GTNH 版 GregTech 与 Applied Energistics 2。
- **支持的整合包版本**：GTNH 2.9.0-beta-1、beta-2、beta-3、RC-1，同一个 JAR 自动适配。
- **可选集成**：TST、GT Not Leisure、TecTech、AE2 Infinity Cell、Programmable Hatches 等。相关功能需要对应模组；上述整合包范围不代表所有历史第三方模组版本都兼容。

## 从哪里开始

### 直接用 ME 库存供料

在多方块机器的输入位置安装以下设备，并接入有电、有可用通道的 ME 网络：

| 设备 | 供应内容 |
| --- | --- |
| 无限存储输入总线 | 物品 |
| 无限存储输入仓 | 流体 |
| 无限存储输入总成 | 物品和流体，共用 360 个标记槽 |

打开界面，标记要供给机器的材料，也可以开启自动标记。**标记只是指定材料，不会凭空产生资源，也不会立即扣料**；配方运行时才从 ME 网络扣取。

三种设备都有 360 个标记槽。自动标记支持最低库存和刷新间隔；物品可按模组、物品 ID、数据值和矿物词典筛选，流体按注册名筛选。最低库存可以输入 `1E18` 等科学计数法。

### 把机器产物送回 ME

| 设备 | 接收内容 |
| --- | --- |
| 无限 ME 输出总线 | 仅物品 |
| 无限 ME 输出仓 | 仅流体 |
| 无限 ME 输出总成 | 物品和流体，可分别设置 |

这些设备自带无限容量缓存，**不需要插入存储元件就能使用**。尚未送入网络的产物会留在缓存中。

可选的存储元件有两种用途：按元件分区过滤产物；开启缓存模式后，优先存入所装元件，供 ME 网络读取。元件本身仍有自己的容量和类型限制。

- 用**线缆剪切器右击**切换 ME 连接面。
- 用**螺丝刀右击**切换缓存模式；输出总成会同时切换物品和流体两侧。
- 输出总成界面中，第一行为物品元件，第二行为流体元件。

> 电解等配方可能同时产生物品和流体。只有物品输出总线还不够，需要配套流体输出仓，或改用输出总成。检查空间不足时，也要确认分区过滤是否允许全部产物通过。

大数输出不要求安装 Apeiron 能源仓；已适配的机器使用自身的有线或无线供电方式时，也能使用这些输出设备。

### 接收 ME 自动合成任务

**无限样板输入总成**提供 360 个样板槽和 24 个独立配方缓冲。每个缓冲可放 32 种物品和 32 种流体，不同配方的材料互不混用。

1. 安装总成、接入 ME 网络，放入编码好的加工样板。
2. 用右侧按钮切换样板／倍数视图，按需设置倍数；倍数保存在总成中，不会改写样板物品。
3. 用右下角按钮查看或取放已送达的材料；可将暂存材料退回 ME，网络无法接收的部分会保留。
4. 配方需要不消耗的电路或催化剂时，用加号设置共享材料，或中键点击样板单独设置。需要消耗的材料仍应写入加工样板。

支持 Programmable Hatches 编程器电路，以及样板管理终端。亚稳态黑洞遏制场仍需正确的模式电路：`20` 为压缩机、`21` 为中子态素压缩机，可在相应催化剂槽中设置。

想让多台机器共享这些样板和材料，可以安装**无限样板输入总成镜像**：用闪存左击源总成，再右击镜像绑定。镜像不复制库存，不额外占用 AE 通道；源总成所在区块需要保持加载。右击镜像即可查看和设置源总成。

## 无线供电、并行和速度

两种能源仓都从 **GT 无线电网账户扣电**，需要账户中有足够能量。在支持的多方块机器上安装后，打开控制器的电源面板调整参数。

| 设置 | 无限能源仓 | 终极无限能源仓 |
| --- | --- | --- |
| 并行上限 | 可调，支持大数 | 可调，支持大数 |
| 默认并行上限 | 2,147,483,647 | 2,147,483,647 |
| 速度设置 | 调整运行电压，遵循机器自身超频规则 | 直接调整完成时间，默认 128 Tick，最低 1 Tick |
| 耗电规则 | 调高电压可能导致有损超频，取决于机器 | 按机器未超频时的基础总耗电扣电，保留机器自身修正；缩短设置时间不增加总耗电 |

并行数可输入 `1E20`（即 10²⁰）。**手动将并行设为 `0` 才表示不设固定上限**；实际执行数量始终受材料、电量、输出空间及机器自身条件限制。“无限”不代表免费能源或无限原料。

正常游戏速度为每秒 20 Tick，因此 128 Tick 为 6.4 秒；服务器卡顿时实际等待时间会更长。

部分机器有额外规则：

- **GTNL 跨配方无线机器**（如超生高速）：装上终极无限能源仓后，无需原生无线升级即可使用无线电网、跨配方执行、大数并行和时间设置。未装 Apeiron 能源仓时，保留 GTNL 原有的基础并行、超频和批量规则；其面板基础并行值不一定等于最终执行数量。
- **太空电梯**：子模块可使用主模块的无限能源仓与无线账户。普通仓保留子模块原有并行上限；终极仓为装配、采矿、抽水模块提供大数并行。
- **诸神之锻模块**：普通能源仓提供大数并行和电压设置；终极仓提供大数并行和完成时间设置。并行设置表示实际配方数量：填 1 执行 1 个，填 2 执行 2 个，奇异物质模块也遵循这个规则。主控提供的热量、速度、耗电折扣及配方解锁继续生效，主控里程碑统计也会更新。兼容 EyeOfHarmonyBuffer 的无输入配置，零输入等待配方可在重载后恢复。
- **量子操纵者**：需要安装下述增强方块，才能使用 Apeiron 能源仓的并行、电压或时间设置。
- **PCB 工厂**：安装能源仓后可设置大数并行，终极仓可设置完成时间。线宽仍影响产出和基础耗电；配方所需的工厂等级、纳米蜂群与生物升级仍需满足。

## 机器增强模块

### 鸿蒙之眼增强模块

替换鸿蒙之眼结构中的一个输入仓位置，右击模块设置：

- **运行时间**：默认 128 Tick，最低 1 Tick；连续配方可衔接取料与工作。
- **成功率**：默认 `0.5`（50%），范围 `0～1`。成功份数按“并行数 × 成功率”计算，不足一份的部分按概率决定。例如，3 并行、50% 成功率会先成功 1 份，另有 50% 概率再成功 1 份。
- 解除星阵数量上限，支持无限存储输入仓、输入总线和输入总成；流体按各自缺口取用。

总耗电仍按鸿蒙之眼原有规则结算。

### 量子操纵者增强方块

替换量子操纵者任意底层仓室／机器外壳位置：

- 物品和流体产物的概率固定为 **100%**。
- 从无限样板输入总成当前样板的编程器电路识别催化剂，无需大宗催化剂仓或实体催化剂。不同样板的材料与催化剂分别处理，也支持总成镜像。
- 配合普通无限能源仓调整并行与电压；配合终极仓调整并行与完成时间。

仍需满足配方等级、材料、电量及输出空间要求；保留流体模式，无需额外聚焦等离子体。未安装增强方块时，使用机器原有的催化剂和概率机制。

## ME 束流输出与粒子供料

**ME 束流输出仓**安装在普通或高级束流输出仓位置，将束流转换为对应粒子物品并送入 ME 网络。断网或分区过滤暂不允许输出时，粒子保留在缓存中，恢复条件后继续输出。

靶室与束流合成器接入无限样板输入总成或有效绑定的镜像后，可按配方提供对应种类和数量的粒子物品，光子也需实际提供。靶室忽略束流电子伏特与聚焦条件；原材料、掩膜、供电和输出空间仍需满足。未接入样板总成时，使用原生束流输入。

束流合成器的大数并行由无限能源仓设置，保留 GTNL 电压带来的产物概率加成。旧版 GT 束流合成器使用不同的配方处理入口，粒子物品增强仅在具备对应处理接口的版本启用。

## 其他 ME 设备

| 设备／功能 | 用法 |
| --- | --- |
| 无限并行处理单元 | 用于 AE2 合成 CPU，提供无限并行处理能力；仍需搭建有效的 CPU 结构。 |
| 无限合成存储器 | 用于 AE2 合成 CPU，提供无限合成存储容量；不会替代材料供应和加工机器。 |
| 无限编程器电路提供器 | 81 个样本槽，将物品样本转换为无限供应的编程器电路；样本不消耗。也可放入预构电路提供器。需要 Programmable Hatches，有效联网时固定耗电 1,024 EU/t。 |
| 创造 ME 物品／流体存储元件适配 | 为所配置资源提供无限供应，在终端中显示 `∞`。 |
| AE2 Infinity Cell 适配 | 支持无限存储元件中的大数库存与存取；存储的资源仍需实际获取。 |

## 配置说明

主要配置在 **`config/apeiron/apeiron.cfg`**，启动后生成。每个选项旁都有用途、影响范围和启用条件。**修改后重启游戏／服务端，客户端与服务端保持一致。**

以下功能开关默认开启。名称中的 `mixins` 是配置分类，正常游玩无需调整它们。

| 分类与选项 | 影响范围 |
| --- | --- |
| `mixins.appliedenergistics2.enableAeMixins` | 核心开关：AE2 大数存储与合成、GT 输入输出与能源适配。关闭也会停用依赖它的可选集成。 |
| `mixins.appliedenergistics2.enableAeSelfRecursiveCrafting` | 默认开启：同一张样板用产物补回同类输入，按每轮净增量规划合成，仍需启动材料与其他原料。 |
| `mixins.sciencenotleisure.enableWirelessIntegration` | GTNL 无线机器的大数输出、耗电、跨配方与 Apeiron 能源仓适配。 |
| `mixins.gregtech.enableBeamlineInputs` | 束流源室的样板输入适配、靶室与支持版本束流合成器的粒子物品输入，以及 ME 束流输出仓结构识别；EyeOfHarmonyBuffer 增强选项独立管理。 |
| `mixins.gregtech.enableQuantumEnhancement` | 量子操纵者增强方块的结构识别和增强效果。 |
| `mixins.gregtech.enableSpaceElevatorIntegration` | 太空电梯子模块的无线能源、并行与输出适配。 |
| `mixins.tectech.enableEyeOfHarmonyEnhancement` | 鸿蒙之眼增强模块的结构识别、时间、成功率与输入适配。 |
| `mixins.tectech.enableEyeOfHarmonyBigOutput` | 鸿蒙之眼的大数输出，与增强模块开关分开控制。 |
| `mixins.twistspacetechnology.enableTstBigOutput` | TST 公共输出及已适配机器的大数输出、专用能源适配。 |
| `mixins.twistspacetechnology.enableTstPatternEncodeGuard` | 避免 TST 在样板编码未产生有效结果时继续转换而报错；不依赖核心开关。 |
| `mixins.aeinfinitycell.enableInfinityCellBigStorage` | AE2 Infinity Cell 的大数显示与存取。 |
| `mixins.programmablehatches.enablePatternOptimization` | Programmable Hatches 优化矩阵与样板倍增的配合。 |
| `mixins.waila.enableLightweightSnapshots` | 精简悬浮提示的数据量。库存与配方显示预览，完整内容在机器界面查看。自定义 OmniOcular 脚本需要完整存档数据时可关闭。 |
| `mixins.network.enablePayloadDiagnostics` | 数据包过大时提供更详细的日志，便于排查；不改变容量，不依赖核心开关。 |

`machines.machineIdStart` 默认 **31300**，为 Apeiron 预留连续 100 个机器编号。仅遇到编号冲突时调整；已有存档应保留原值，以免机器和物品对应错误。

`tst-unlimited-parallel.cfg` 和 `gtnl-unlimited-parallel.cfg` 是**预留的原生无限并行选项**，默认关闭，当前版本仅保存选择，不直接改变机器运行。使用 Apeiron 能源仓时，在机器电源面板设置并行即可，不需要开启这两个文件中的选项。
