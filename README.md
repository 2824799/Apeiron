# Apeiron

Apeiron 是面向 GT New Horizons（Minecraft 1.7.10）的扩展模组，主要解决 AE2、样板、合成 CPU 和 GT 机器在大数量、无限缓存与超大并行方面的限制。

## 主要功能

- AE2 物品和流体数量支持任意精度，终端、合成计划、CPU 状态和机器提示会显示完整数量。
- 合成请求、样板倍数、机器并行、EU/t、输出队列和无线能源扣款支持超出 `long` 的数值。
- 创造 ME 物品／流体存储元件可作为无限供应源，终端中显示为 `∞`。
- 支持 GT 多方块机器向 ME 网络输出超大数量的物品和流体。
- 提供无限合成 CPU 部件，适合需要超大存储容量或并行数的 AE2 网络。
- 对 TST、GT Not Leisure、TecTech、AE2 Infinity Cell 和 Programmable Hatches 提供可选适配。

## 方块

| 方块 | 用途 |
| --- | --- |
| **无限 ME 输出总线** | 多方块机器的物品输出端。物品直接进入 ME 网络，缓存没有固定数量上限，可插入物品存储元件进行分区过滤。 |
| **无限 ME 输出仓** | 多方块机器的流体输出端。功能与无限 ME 输出总线对应，但处理流体和流体存储元件。 |
| **无限 ME 输出总成** | 在一个 ME 连接中同时提供物品输出和流体输出。物品、流体各自拥有独立缓存、设置和存储元件槽位。 |
| **无限样板输入总成** | 提供 360 个样板槽和 24 个隔离缓冲，支持物品、流体、样板倍数、催化剂、配方锁定和样板优化。可在样板管理终端中显示和管理。 |
| **无限样板输入总成镜像** | 通过闪存绑定源总成，共享源总成的样板和缓冲，不复制库存，也不额外占用 AE 通道。 |
| **无限能源仓** | 直接从 GT 无线电网扣除能量，不使用本地电池。安装到支持的机器后，并行数设为 `0` 可表示无限上限；也可以输入任意大的固定并行数。 |
| **无限并行处理单元** | AE2 合成 CPU 的并行部件，提供无限并行能力。 |
| **无限合成存储器** | AE2 合成 CPU 的存储部件，不受普通存储器的固定容量限制。 |

## 基本使用

1. 将 ME 输出总线、输出仓或输出总成接入 ME 网络，再安装对应的存储元件或过滤设置。
2. 将无限样板输入总成接入网络并写入样板；需要共享时，用闪存左击源总成，再右击镜像。
3. 将无限能源仓安装到已接入 Apeiron 适配的 GT 机器。机器的并行设置为 `0` 时启用无限上限；无线电网余额不足时机器会暂停。
4. 将无限并行处理单元和无限合成存储器组成 AE2 合成 CPU。它们必须与 AE2 的其他 CPU 结构规则一起使用。

## 注意事项

- 无限能源仓的实际并行仍受材料、输出空间、机器处理逻辑和无线电网余额影响。
- 大数量功能需要客户端和服务端同时安装 Apeiron。
- 部分适配属于可选功能，可在 `config/apeiron/apeiron.cfg` 中按模组开关控制。
- 需要避免 Apeiron 的 GregTech 机器 ID 保留区间与其他模组冲突；默认起始 ID 为 `31300`。

## 依赖与许可证

Apeiron 运行时依赖 GT New Horizons 的 GregTech 和 Applied Energistics 2。TST、GTNL、TecTech、AE2 Infinity Cell、Programmable Hatches 等属于可选集成。
