`mixin/tst/output/ParallelOutputBigMixin.java` adapts the output chance calculation from Twist Space Technology `0.8.0-RC1.3`, commit `a780af281b9c4539098004461fc0701d0bbff5c3`, by Nxer and contributors. The original source is `GTCM_ParallelHelper.java`; modified source is included in this repository and source JAR. Twist Space Technology remains an optional external dependency.

The infinite pattern input assembly and mirror in `common/machine/me/input/` adapt the recipe isolation, programming selector, pattern multiplier and coordinate linking logic of Programmable Hatches `0.2.0p26` by reobf. These portions and Apeiron's changes are provided under MIT; see `licenses/Programmable-Hatches-MIT.txt`. They use Apeiron-owned exact inventories and independent registrations. Programmable Hatches' programming-circuit item remains interoperable without patching its original blocks.

`client/gui/machine/me/input/InfinitePatternInputGui.java` derives its scrolling pattern grid and catalyst dialog layout from GT Not Leisure's `SuperCraftingInputHatchMEGui`, by ABKQPO and contributors, under GPL-3.0; see `licenses/GNU-GPL-3.0.txt`. Changes add a 360-slot shared scroll position for pattern/multiplier views, block-local exact multiplier editors, and separate item/fluid buffer panels. GregTech textures are referenced from GregTech's resources. Modified sources are included in this repository and the source JAR.

The infinite programming circuit provider in `common/machine/me/circuit/` adapts the circuit wrapping and ME host lifecycle of Programmable Hatches' `ProgrammingCircuitProvider` under MIT. Its original prefabricated provider and programming-circuit item remain optional external APIs. Changes add an 81-slot sample inventory, a renewable ME storage backend and a fixed idle cost equivalent to 1024 EU/t. Existing Programmable Hatches textures are referenced from that mod's resources.

The storage inputs in `common/machine/me/stocking/` and `client/gui/machine/me/input/InfiniteStorageInputGui.java` adapt the phantom selection, filter, recipe snapshot and GUI concepts of GT Not Leisure's `SuperInputBusME`, `SuperInputHatchME`, `SuperDualInputHatchME`, `TypeFilteredInputBusME`, `OredictInputBusME` and their GUI classes under GPL-3.0. Apeiron's versions use 360 selections, exact counts, unified filters, scientific notation, atomic recipe extraction and persistent recovery of rejected refunds. They do not require GT Not Leisure at runtime. Original and modified license terms are included in this repository and distributed JARs.
